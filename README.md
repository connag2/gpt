# VocaFlow Codex Prompt Kit

이 저장소는 **Codex에 바로 넣어 실행하기 좋은 영단어 암기 앱 프롬프트**를 담고 있습니다.

## 포함 파일
- `CODEX_PROMPT_KR.md`: 한국어 최종 프롬프트(복붙용)

## 사용법
1. `CODEX_PROMPT_KR.md` 내용을 통째로 복사합니다.
2. Codex에 붙여넣고 실행합니다.
3. 생성된 코드에서 우선 실행 확인 후, 필요 기능을 2차로 확장합니다.

## 핵심 컨셉
- 빠른 입력(여러 줄 복붙 + txt 불러오기)
- 단순하고 가독성 높은 UI
- 오답 자동 반복 + 간단한 spaced repetition
- 안정성 우선(저장 누락/중복 저장/UI 미갱신 방지)
